FLUSING:
  /* no flushing */
  printf("Hello world");
  for (;;) { }
  /* output : nothing */

  /* with flushing */
  printf("Hello world");
  fflush(stdout);
  for (;;) { }
  /* output : Hello world */

Q What is buffering?
> Buffer :
  a temp holding area inside FILE* 
  instead of one syscall per byte,
  we batch a whole chunk.

[ our buffer in FILE* ]   <- buffering (stdio)
        │ fflush()
        V
[ OS page cache ]         <- kernel's own buffer
        │ fsync()
        V
    [ disk ]

Q Why buffered or why wait can't we sent it directly to os?
> to avoid syscall per bytes

BUFFRING IN FILE*:
stdin:
  terminal:       (new line buff) goes directly to os
  file/pipe:      (full buffered) flush on full, fflush, fclose, exit
stdout
  terminal:       (new line buff) flush on full, fflush, fclose, exit, \n
  file/pipe:      (full buffered) flush on full, fflush, fclose, exit
stderr:           (unbuffered)    every call gets the os
file/pipe/socket: (full buff)     flush on full, fflush, fclose, exit
